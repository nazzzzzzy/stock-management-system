# Team Test Checklist

Use this checklist when verifying the improved Stock Management System.

## Desktop application

1. Start the desktop application.
2. Confirm that the main window loads with product cards.
3. In the search bar, type part of a product name and confirm the list filters correctly.
4. Search by product ID and confirm the matching product appears.
5. Turn on **Low stock only** and confirm only products at or below reorder point remain visible.
6. Click **Clear** and confirm all products return.
7. Add a valid product and confirm it appears in the list.
8. Try to add a product with invalid values such as reorder point greater than quantity and confirm the system blocks it.
9. Sell a product and confirm quantity updates.
10. Restock a product and confirm quantity updates.
11. Delete a product and confirm it is removed.
12. Open the report window and confirm totals display.

## Web dashboard

1. Start the web dashboard.
2. Log in using the default account.
3. Upload a valid `.db` file generated by the desktop application.
4. Confirm the dashboard summary cards load.
5. Confirm the sales records table loads.
6. Confirm the trend and top-product charts load.
7. Try accessing an API endpoint without logging in and confirm it is blocked.
8. Try uploading an invalid file and confirm it is rejected.

## Final submission check

1. Confirm the README opens and clearly explains how to run both modules.
2. Confirm the repository includes the improvement summary and this checklist.
3. Confirm the team understands which features were changed before presenting or submitting.
